# Cronaldo Sports - Premium Football Jerseys E-commerce

A modern React-based e-commerce website for premium football jerseys and sports gear.

## 🚀 Features

- **SEO Optimized**: Complete meta tags, structured data, and sitemap
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Product Catalog**: Official jerseys from top football clubs
- **Product Details**: Detailed product pages with customization options
- **Modern UI**: Clean, professional design with smooth animations

## 📱 SEO Implementation

### Meta Tags
- Complete Open Graph tags for social media sharing
- Twitter Card support
- Structured data for products and business
- Canonical URLs and sitemap

### Files Added
- `src/components/SEO.tsx` - Dynamic SEO component
- `public/sitemap.xml` - XML sitemap for search engines
- `public/robots.txt` - Search engine crawling instructions
- `public/browserconfig.xml` - Windows tile configuration

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Routing**: React Router DOM

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
